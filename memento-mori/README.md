# Memento Mori · KAPUSTKA — кинетическая типографика

Ролик-тизер Telegram-канала **«Memento Mori» от KAPUSTKA**.

**Идея:** каждый день — это сообщение. Их примерно 30 000 на жизнь, а мы листаем
ленту, не открывая: *потом, потом, ПОТОМ*. Обрыв — счётчик непрочитанных
превращается в «?»: сколько осталось, не видно. Остаётся одно сообщение —
**«сегодня»**. Тап — оно открывается (единственное цветное слово), ✓✓ прочитано.
*Memento mori — не про смерть, а про то, чтобы не пролистать жизнь.*
Финал — карточка канала, «Подписаться» → «Вы подписаны», MEMENTO MORI · KAPUSTKA.

Текст — главный герой: крупные слова, контраст размеров и начертаний, один цвет
(`СЕГОДНЯ`). Слова садятся на музыкальную сетку 100 BPM через маски, сдвиги,
масштаб и ракурс (лента на наклонной плоскости в перспективе).

Режиссура и раскадровка: [`storyboard.md`](storyboard.md).

## Результат
`memento-mori.mp4` — 1920×1080, 60 fps, H.264 / yuv420p, звук AAC, 32.4 c.

## Исходники
| Файл | Назначение |
|---|---|
| `index.html` | Детерминированный рендерер на Canvas: `window.__renderAt(t)`. Камера с параллаксом, интерфейс Telegram (баннер, пузыри, бейдж-одометр, лента, карточка, кнопка), таймлайн слов, motion blur, свечение единственного цветного слова. |
| `audio.js` | Музыка и звуковой дизайн (синтез, сайдчейн, ревербератор) → `audio.wav`. |
| `render.js` | Рендер всех кадров `i/60` в несколько процессов Chromium; `--proof` — ключевые кадры. |
| `build.sh` | Полный конвейер: звук → кадры → FFmpeg → `memento-mori.mp4`. |

## Пересборка
```bash
bash build.sh
```
Нужны Node, Playwright + Chromium (`/opt/pw-browsers/chromium`), FFmpeg
(libx264, aac) и шрифты Inter / Inter Display / DejaVu Serif / JetBrains Mono.

Звук синтезирован и проверен по структуре, уровням и привязке акцентов к кадрам;
прослушать его в среде сборки нельзя.
