# Memento Mori · OFF. KAPUSTKA — кинетическая типографика

Ролик-тизер Telegram-канала **«Memento Mori» · OFF. KAPUSTKA**.

**Идея:** каждый день — это сообщение. Их примерно 30 000 на жизнь, а мы листаем
ленту, не открывая — сообщения летят на нас туннелем: *потом, потом, ПОТОМ*.
Скорость сворачивается в кардиограмму, пульс учащается — прямая линия.
Она схлопывается в «?»: сколько осталось, не видно. Остаётся одно сообщение —
**«сегодня»**. Тап — удар пульса, оно открывается (единственное цветное слово,
фирменный красный канала), ✓✓ прочитано.
*Memento mori — не про смерть, а про то, чтобы не пролистать жизнь.*
А ещё — **розыгрыши** (повезти может *сегодня*) и **реакции** на постах:
тап по 💀 — «пусть знают, что ты жив». Финал — карточка канала с аватаркой,
«Подписаться» → «Вы подписаны», MEMENTO MORI / OFF. KAPUSTKA.

Текст — главный герой: крупные слова, контраст размеров и начертаний, один цвет
(`СЕГОДНЯ`, красный обложки `#e3403b`). Слова садятся на музыкальную сетку
100 BPM через маски, сдвиги, масштаб и ракурс (туннель сообщений в перспективе).

Шрифты (`fonts/`, все под SIL Open Font License — файлы лицензий рядом):
Unbounded (широкий), Oswald (узкий, как на обложке), Onest (интерфейс),
Cormorant Garamond Italic (голос автора); системный JetBrains Mono.

Режиссура и раскадровка: [`storyboard.md`](storyboard.md).

## Результат
`memento-mori.mp4` — 1920×1080, 60 fps, H.264 / yuv420p, звук AAC, 37.8 c.

## Исходники
| Файл | Назначение |
|---|---|
| `index.html` | Детерминированный рендерер на Canvas: `window.__renderAt(t)`. Камера с параллаксом, интерфейс Telegram (баннер, пузыри, бейдж-одометр, туннель сообщений, кардиограмма, пост-розыгрыш, реакции, карточка, кнопка), таймлайн слов, motion blur, свечение единственного цветного слова. |
| `avatar.jpg` | Аватарка канала (квадрат 512 px). |
| `fonts/` | Шрифты и их лицензии OFL. |
| `audio.js` | Музыка и звуковой дизайн (синтез, сайдчейн, ревербератор) → `audio.wav`. |
| `render.js` | Рендер всех кадров `i/60` в несколько процессов Chromium; `--proof` — ключевые кадры. |
| `build.sh` | Полный конвейер: звук → кадры → FFmpeg → `memento-mori.mp4`. |

## Пересборка
```bash
bash build.sh
```
Нужны Node, Playwright + Chromium (`/opt/pw-browsers/chromium`), FFmpeg
(libx264, aac), системные JetBrains Mono и Noto Color Emoji; остальные шрифты лежат в `fonts/`.

Звук синтезирован и проверен по структуре, уровням и привязке акцентов к кадрам;
прослушать его в среде сборки нельзя.
