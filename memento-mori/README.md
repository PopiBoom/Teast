# Memento Mori — кинетическая типографика

Ролик-тизер для телеграм-канала **«Memento Mori» от капустки**.

Главный герой — **текст**: крупные слова, контраст размеров и начертаний,
**одно ключевое слово выделено цветом** (`ЖИВИ` — янтарь). Слова появляются
в ритм музыки через сдвиги, маски, смену масштаба и ракурса; каждое слово
держится достаточно, чтобы его прочитать.

История: латинское *memento mori* («помни, что умрёшь») проживает стоический
поворот в *memento vivere* («помни, что надо жить»). Падение, обвал правды в
прах — и перелом: единственное цветное слово `ЖИВИ` вспыхивает, и всё, что
падало, поднимается. Подпись — капустка.

Полная режиссёрская раскадровка: [`storyboard.md`](storyboard.md).

## Результат
- `memento-mori.mp4` — **1920×1080, 60 fps, H.264 / yuv420p, звук AAC**, ~22 c.

## Исходники
| Файл | Назначение |
|---|---|
| `index.html` | Детерминированный рендерер на Canvas: `window.__renderAt(t)` рисует кадр для времени `t` (сек). Псевдо-3D камера с параллаксом, слои пыли/угольков, таймлайн слов (`CUES`), motion blur, свечение/CA единственного цветного слова, распад в прах, зерно/виньет. |
| `audio.js` | Синтез музыки + SFX (аддитивный синтез, ревербератор Шрёдера) → `audio.wav`. |
| `render.js` | Рендер всех кадров `i/60` через headless Chromium (Playwright) → `frames/`. `--proof` рендерит ключевые кадры в `proof/`. |
| `build.sh` | Полный конвейер: `audio.js` → `render.js` → FFmpeg mux → `memento-mori.mp4`. |

## Пересборка
```bash
bash build.sh
```
Требуется Node, Playwright + Chromium (`/opt/pw-browsers/chromium`), FFmpeg
(libx264, aac) и кириллические шрифты Inter Display / DejaVu Serif / JetBrains Mono.

## Технические заметки
- Таймлайн полностью детерминирован: кадр = чистая функция времени, звук
  рассчитан по тем же таймкодам (карта синхронизации — в `storyboard.md`).
- Звук синтезирован и проверен по технической структуре и RMS-огибающей
  (динамическая арка, отсутствие клиппинга, длительность); аудио-прослушивание
  в среде сборки недоступно.
