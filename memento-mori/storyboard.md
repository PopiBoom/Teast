# Memento Mori — кинетическая типографика

Ролик-титул / тизер для телеграм-канала **«Memento Mori» от капустки**.
Главный герой — **текст**. Крупные слова, контраст размеров и начертаний,
**одно ключевое слово выделено цветом**. Слова появляются в ритм музыки:
сдвиги, маски, смена масштаба и ракурса; каждое слово держится достаточно,
чтобы его прочитать.

- Формат: **1920×1080, 60 fps, H.264 / yuv420p, звук AAC**.
- Длительность: **~22 c** (1320 кадров на сетке `i/60`).
- Технический стек: прямой HTML/Canvas + собственный детерминированный
  таймлайн `renderAt(t)`; звук синтезируется в Node (WAV → AAC); сборка
  кадров и mux — FFmpeg.

## Единая нить (история)

«Memento mori» обычно читают как мрачное предупреждение: *помни, что умрёшь*.
Но настоящий поворот этой мысли — **стоический**: память о смерти не пугает,
а возвращает ценность настоящему. Ролик проживает этот поворот **самой
типографикой**.

Причинная цепочка: **часы идут → приходит напоминание о смерти → холодная
правда (ты умрёшь) → провал/пустота → перелом → разворот к жизни → настоящее →
подпись.** Слова сначала тяжёлые, падают вниз (гравитация, прах, вес смертности);
правда «ты умрёшь» рушится в прах; затем — **вольта**: единственное цветное
слово **ЖИВИ** вспыхивает тёплым янтарём, и всё, что падало, начинает
подниматься. Латинское «memento mori» оборачивается в «memento vivere» —
*помни, что надо жить*. Подпись — капустка.

Это не перечисление слов, а развитие одной мысли с переломом в середине.
Контраст «мягкое имя автора ↔ тягчайшая тема» — часть замысла.

## Визуальная грамматика

| Элемент | Решение |
|---|---|
| Палитра | Почти чёрный фон `#0a0a0d` с холодным пепельным виньетом; текст — костяной белый `#ece7df` и пепел `#8a867e`. На вольте фон теплеет. |
| **Один цвет** | **ЖИВИ** — тёплый янтарь-уголёк (градиент `#ff7a2d → #ffd27a`) с мягким свечением. Больше **ни одно** слово не цветное (строгая дисциплина одного акцента). |
| Начертания | **Inter Display** от Thin до Black — контраст веса; **serif** (DejaVu/Liberation Serif) для тихих рефлексивных строк; **JetBrains Mono** для «часов/праха» (счётчик, даты). Контраст размеров: от крошечной подписи до слова во весь экран. |
| Глубина | Псевдо-3D проектор (перспективное деление): дальний слой пыли, средний слой гигантских «призрачных» букв, передний — активные слова. Параллакс при проезде камеры. |
| Камера | Непрерывная связная траектория: медленный наезд в интро, боковой дрейф с параллаксом, наклон на «правде», подъём на вольте. Волны скорости, не одинаковый ease на каждом бите. |
| Оптика | Направленный motion blur на быстрых входах (мультисэмпл вдоль вектора); радиальный zoom-blur-акцент на ударах; мягкое свечение/bloom на цветном слове; зерно и виньет; лёгкая хроматическая аберрация на вспышке ЖИВИ. |
| Приёмы входа | **сдвиг** (slide), **маска** (клип-вайп), **масштаб** (scale), **ракурс** (roll + перспектива). Каждое окно чтения ≥ ~0.7 c для коротких слов, больше для фраз. |

## Раскадровка по сценам

Для каждой сцены — короткие варианты и выбранный (сильнейший для общего
развития), затем карточка.

### S1 · Часы (0.0–2.6 c)
Варианты: (a) мигающий mono-курсор + счётчик секунд; (b) песок/пыль оседает;
(c) пульс-линия ЭКГ. **Выбрано: (a)+частицы праха** — задаёт «время идёт»
минимально и в духе телеграм-канала (моноширинный «системный» голос).
- Смысл/время: пролог, завести часы. 0.0–2.6.
- Текст: `рано или поздно` — крошечный пепельный mono снизу; сверху тикающий счётчик.
- Камера/оптика: медленный наезд из темноты, пылинки в параллаксе, сильный виньет.
- Звук: тихий дрон + мягкий тик часов. Вход: из чёрного.

### S2 · MEMENTO MORI (2.6–5.4 c)
Варианты: (a) оба слова падают сверху с ударом; (b) проявляются сквозь маску
снизу вверх; (c) наезд сквозь гигантскую букву «O» из MORI. **Выбрано: (a)
падение + маска у MORI** — вес и гравитация = тема смертности; удар ставит ритм.
- MEMENTO — огромный Inter Display Black, костяной белый, лёгкий ракурс (roll+перспектива), падает и тормозит с motion blur.
- MORI — ниже, другой масштаб, въезжает маской-вайпом; вместе читается MEMENTO MORI.
- Камера: микронаклон на удар; радиальный акцент на контакте. Звук: суб-удар + дрон раскрывается.

### S3 · Перевод (5.4–7.6 c)
Варианты: (a) serif-строка проявляется маской под титулом; (b) буквы
собираются из праха; (c) печатная машинка mono. **Выбрано: (a) serif-маска** —
смена гарнитуры (Black → тонкий serif) = смена голоса на тихий.
- Текст: `помни, что ты умрёшь` — тонкий serif, курсив, окно чтения ~2 c.
- Камера: спокойный дрейф вбок, параллакс призрачного «M» на среднем слое.

### S4 · Каждый вдох (7.6–10.2 c)
Варианты: (a) слова-вспышки в ритм сердца; (b) вдох-выдох — масштаб дышит;
(c) лесенка слов по диагонали. **Выбрано: (b)+(a)** — масштаб «дышит» в такт.
- Текст по битам: `каждый` · `вдох` (крупно) · `—` · `на один` · `ближе` (контраст размеров, сдвиги).
- Звук: сердцебиение (lub-dub) ведёт ритм; каждое слово на удар. Камера: лёгкий дрейф.

### S5 · Правда и провал (10.2–12.8 c)
Варианты: (a) `умрёшь` во весь экран рушится в прах вниз; (b) слово выгорает;
(c) схлопывается в точку. **Выбрано: (a) обвал в прах** — кульминация падения,
дно арки.
- Текст: `ты` (мелко) → `УМРЁШЬ` (во весь экран, Black) → распад маской сверху-вниз в частицы.
- Камера: наклон вниз, затем провал в черноту. Звук: музыка духается, низкий хвост, «crumble» SFX.

### S6 · Петля (12.8–13.8 c)
`и всё же.` — крошечный mono по центру на чёрном. Один низкий тон. Пауза-перелом.

### S7 · ВОЛЬТА — ЖИВИ (13.8–17.4 c)
Варианты: (a) искра разгорается в слово; (b) слово встаёт из праха снизу
вверх (разворот падения); (c) вспышка из центра с хром. аберрацией.
**Выбрано: (b)+(c)** — то, что падало, теперь **поднимается**; единственный цвет.
- Текст: тихо `не чтобы бояться,` → затем **ЖИВИ** — во весь экран, **янтарный градиент + свечение**, масштаб из искры, фон теплеет, bloom.
- Камера: подъём вверх (разворот S5), лёгкий облёт. Звук: восходящий swell, минор → тёплый мажорный аккорд, удар + колокольчик.

### S8 · Настоящее (17.4–19.6 c)
- Текст: `сегодня` · `ты` · `есть` оседают вокруг ЖИВИ (монохром, тёплый оттенок), затем `memento vivere` — тонкий serif (разворот латыни).
- Камера: мягкая дуга к покою. Звук: аккорд держится, светлый слой.

### S9 · Подпись (19.6–22.0 c)
- Финальный читаемый кадр: сверху мелко `MEMENTO MORI` (где начинали), по центру тёплый росчерк `капустка` и строка `memento vivere`.
- Камера: замирает. Звук: тёплый сустейн с длинным reverb-хвостом. Удержание ~1.5 c.

## Риски и проба
Главный риск — читаемость крупных кириллических слов при motion blur и
свечении + ровность 60 fps детерминированного рендера. Проверяется пробным
рендером ключевых кадров (MEMENTO MORI, УМРЁШЬ-распад, ЖИВИ-вспышка) до полной
сборки, затем полной итерацией по декодированному MP4.
